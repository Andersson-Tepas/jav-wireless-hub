# JAV Wireless — sitio comercial y dashboard

## Objetivo
Construir una experiencia responsive en español para mostrar servicios, productos, financiamiento y reparaciones, junto con un dashboard operativo visual.

## Páginas y navegación
- Crear Inicio, Servicios, Productos, Financiamiento, Reparaciones, Nosotros, Contacto y Dashboard como páginas separadas.
- Añadir una navegación compartida, menú móvil y botón flotante de WhatsApp.
- Incorporar enlaces visibles a WhatsApp, Facebook, Instagram y TikTok.

## Experiencia visual
- Aplicar fondo oscuro con identidad azul eléctrico, cyan, rojo y blanco.
- Diferenciar categorías: Servicios azul, Productos cyan, Ofertas rojo, Financiamiento dorado, Reparaciones gris/azul y Envíos azul/verde.
- Usar una composición tecnológica, compacta y clara, con tarjetas interactivas y adaptación completa para PC y celular.

## Productos y acciones
- Crear un catálogo demostrativo de teléfonos y accesorios.
- Abrir cada producto en un modal dinámico con imagen, marca, modelo, precio, stock, color, capacidad, descripción, características, especificaciones y financiamiento.
- Añadir acciones Consultar, Comprar y Reservar; cierre con X, clic exterior y tecla ESC.

## Dashboard
- Crear accesos rápidos y paneles visuales para formularios, clientes, envíos, pagos y reportes.
- Mantenerlo como experiencia demostrativa de interfaz, sin almacenamiento de datos ni pagos reales.

## Contenido y calidad
- Incluir contenido comercial de muestra claramente editable.
- Añadir metadatos únicos para cada página.
- Verificar compilación, navegación, modal, cierre por teclado/clic exterior y presentación en escritorio y celular.
